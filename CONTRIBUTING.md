# Contributing

Thank you for improving the SellViaApp Odoo connector.

1. Create a focused branch from `17.0`.
2. Keep changes compatible with Odoo 17 and the module's LGPL-3.0 licence.
3. Never add credentials, production payloads or identifiable customer data.
4. Add or update English documentation for user-visible behaviour.
5. Run `python tools/validate_module.py`.
6. Test installation or upgrade in a disposable Odoo database.
7. Describe behaviour, validation and migration impact in the pull request.

Use conventional, imperative commit messages such as `Fix customer matching fallback`.
