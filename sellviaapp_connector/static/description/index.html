Connect Odoo to a mobile catalogue and a complete API

Synchronise products, categories, variants, images, stock and customers. Retrieve confirmed mobile orders as Odoo quotations, with incremental jobs built for large catalogues.

Catalogue and stock

Publish FAM1/FAM2 categories, products, variants, prices, tax data, attributes and up to five images. Refresh stock through a lightweight endpoint without resending full product records.

Customer access

Send eligible Odoo contacts to SellViaApp, issue mobile invitations, or retrieve customers created in SellViaApp with duplicate-safe matching.

Mobile orders

Retrieve confirmed orders as draft quotations. Product bindings, customer details, delivery or pickup data, payment status and comments are preserved.

One integration, two powerful outcomes

Mobile commerce and API access

The connected SellViaApp account powers a customer-facing iOS and Android experience and provides authenticated API families for catalogue, customers, orders, fulfilment, payments, integrations and webhooks.

Representative resources include product and image lists, FAM1/FAM2 categories, customer records, carts, orders, stock updates, shipping quotes and event delivery history.

Optional private catalogue

Invisible to the public, available to authorised accounts

Private-catalogue mode is configured in SellViaApp. The space can be hidden from the public directory while mobile access is restricted to accounts approved by the business.

  • Authorised customer accounts
  • Revocable OAuth connection
  • Biometric access on compatible devices
  • Session and device controls in SellViaApp

Designed for reliable daily operations

Security by design

  • OAuth 2.0 device authorisation
  • Operations locked until authentication succeeds
  • Credentials restricted to Odoo administrators
  • HTTPS required in production
  • Signed image access and revocable tokens
  • Incremental batches and duplicate protection

Five-minute guided setup

Install the module, open SellViaApp in Odoo, approve the displayed code, complete the connection and choose the first synchronisation. The password is never shared with Odoo.

Requires Odoo 17, the standard Sales and Inventory applications, outbound HTTPS access and an active SellViaApp account.
